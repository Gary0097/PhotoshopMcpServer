# 端行现场交付检查表

## 一、客户提前准备

- [ ] 已购买可用的 GPT 账号/服务。
- [ ] 已安装 Codex，并使用上述账号登录成功。
- [ ] VPN 专线已经连接。
- [ ] Photoshop 2026 已安装、激活并能手动打开。
- [ ] Illustrator 2026 已安装、激活并能手动打开。
- [ ] 现场人员具有安装权限。
- [ ] 已准备一张非敏感测试图和一张代表性工艺样板。

## 二、双击安装

1. 双击仓库根目录的 `检查端行作图环境.cmd`。
2. 所有自动检查显示“通过”。
   - 若“Photoshop 64 位控制文件”未通过，双击 `修复Adobe自动控制.cmd`，完全关闭 PS/Codex 后重新检查。
3. 人工确认 GPT、VPN 和 Adobe 授权三项。
4. 双击 `安装端行作图助手.cmd`。
5. 看到“安装完成”后关闭旧 Codex 任务，打开新任务。
6. 再次双击安装程序，确认显示“插件来源已经存在，自动跳过”和“作图服务健康检查：通过”。
7. 双击 `运行端行Adobe现场自检.cmd`，确认 PS 和 Illustrator 都能创建、保存测试文件。
8. 双击 `运行端行完整流程自检.cmd`，确认自动完成建任务、检查版、复核绑定和 TIFF 生产导出。

安装器可重复运行并用于更新。若检测到同名但来自其他目录的插件来源，会停止并给出中文提示，不会自动删除其他插件配置。
