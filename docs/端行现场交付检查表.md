# 端行现场交付检查表

## 一、客户提前准备

- [ ] 已购买可用的 GPT 账号/服务。
- [ ] 已安装 Codex，并使用上述账号登录成功。
- [ ] VPN 专线已经连接。
- [ ] Photoshop 2026 已安装、激活并能手动打开。
- [ ] Illustrator 2026 已安装、激活并能手动打开。
- [ ] 现场人员具有安装权限。
- [ ] 已准备一张非敏感测试图和一张代表性工艺样板。

## 二、双击安装

1. 保存工作并完全关闭 Photoshop 和 Illustrator。
2. 双击仓库根目录的 `【客户双击这里】首次安装端行作图助手.cmd`。
3. 人工确认 GPT、VPN 和 Adobe 授权三项。
4. 确认环境检查、插件安装、Adobe 自检和完整业务流程自检均通过。
5. 看到“一键部署已经完成”后关闭旧 Codex 任务，打开新任务。
6. 再次运行一键部署，确认已有插件来源能够自动跳过并完成更新检查。

若自动修复了 Photoshop 连接，一键部署会停止并提示完全关闭 Photoshop 和 Codex 后再运行一次。独立检查、修复、安装和自检入口都在“实施人员工具”文件夹。

安装器可重复运行并用于更新。若检测到同名但来自其他目录的插件来源，会停止并给出中文提示，不会自动删除其他插件配置。
