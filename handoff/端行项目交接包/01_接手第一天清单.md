# 接手第一天清单

## 1. 同步与确认版本

```powershell
git pull
git log -1 --oneline
```

确认分支为 `master`，并阅读 `00_交接总览.md`。

## 2. 检查客户前置条件

- GPT/ChatGPT 已购买、账号可登录。
- Codex 桌面端已安装并登录。
- Photoshop 2026、Illustrator 2026 已安装；当前目标路径在 `K:\TOOL`。
- VPN 专线/外网可用。

## 3. 首次安装

关闭 Codex、Photoshop、Illustrator，双击仓库根目录：

`【客户双击这里】首次安装端行作图助手.cmd`

安装完成后重新打开 Codex，并新建一个任务，不要只在旧任务里测试。

## 4. 现场验证

依次运行 `实施人员工具` 中：

1. `3-检查端行作图环境.cmd`
2. `4-验证端行MCP工具.cmd`
3. `7-验证客户中文回答.cmd`

预期结果：Photoshop/Illustrator 可发现，39 个客户中文工具通过，客户帮助/恢复/下一步回答合格。

## 5. 样板确认

打开 `样板产物` 中的底图 V2 和 2×2 检查图。先向客户确认纹理质感与明暗方向，不要把它称为最终无缝稿。

## 6. 客户确认后的实施顺序

1. 在原始 19,000 × 15,000 TIF 上做全分辨率去波纹与底纹补全。
2. 做水平、垂直偏移和 2×2 拼接检查，清除接缝、竖纹和暗格线。
3. 清理 877 条矢量路径，建立四边可衔接的矢量单元。
4. 在 Illustrator 中做四向拼接目检。
5. 保持原图灰度关系，仅优化清晰度、柔和过渡、饱满度和通透层次。
6. 导出客户约定格式，保留过程文件、参数和验收截图。

## 7. 交付前记录

- 记录原文件和最终文件的 SHA-256。
- 记录 Photoshop/Illustrator/Codex/插件版本。
- 保存 1×1、2×2、偏移接缝检查图。
- 让客户确认底图、波纹矢量和整体层次三个独立验收项。
