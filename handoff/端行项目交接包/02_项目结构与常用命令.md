# 项目结构与常用命令

## 关键入口

- `README.md`：项目入口与总体说明。
- `PRD.md`：产品需求与范围。
- `IMPLEMENTATION_WORKFLOW.md`：实施流程。
- `plugins/duanxing-creative-automation`：Codex 插件主体。
- `plugins/duanxing-creative-automation/skills/duanxing-image-craft/SKILL.md`：客户中文 Skill 主入口。
- `docs/端行客户使用手册.md`：客户操作手册。
- `docs/端行中文口令卡.md`：客户常用口令。
- `docs/端行现场交付检查表.md`：现场实施核对项。
- `docs/端行当前版本自动验收记录.md`：当前自动验收证据。
- `实施人员工具`：现场双击工具。

## Skill 的分层参考

- `references/daily-workflow.md`：日常工作流。
- `references/wave-separation-workflow.md`：波纹分离流程。
- `references/ai-vector-workflow.md`：Illustrator 矢量流程。
- `references/deployment.md`：部署流程。

## 安装插件

```powershell
pwsh -NoProfile -ExecutionPolicy Bypass -File .\scripts\安装端行作图助手.ps1 -SkipEnvironmentCheck
```

## 验证环境和协议

```powershell
pwsh -NoProfile -ExecutionPolicy Bypass -File .\scripts\检查端行作图环境.ps1
pwsh -NoProfile -ExecutionPolicy Bypass -File .\scripts\验证端行MCP工具.ps1
pwsh -NoProfile -ExecutionPolicy Bypass -File .\scripts\验证客户中文回答.ps1
```

## 完整自检

```powershell
pwsh -NoProfile -ExecutionPolicy Bypass -File .\scripts\运行端行完整流程自检.ps1
pwsh -NoProfile -ExecutionPolicy Bypass -File .\scripts\运行端行Adobe现场自检.ps1
```

## 插件修改后刷新版本

```powershell
python -X utf8 C:\Users\Gary\.codex\skills\.system\plugin-creator\scripts\update_plugin_cachebuster.py .\plugins\duanxing-creative-automation
```

刷新后重新安装插件，并在一个全新的 Codex 任务中测试客户中文口令。

## Git 注意事项

本机如触发 Git safe.directory，使用：

```powershell
git -c safe.directory='C:/Users/Gary/Documents/ChatGPT/图片生成/DuanxingPhotoshopPlugin' status
```

不要提交 `tmp`、客户原始大图、账号、Cookie、API Key 或本机日志。
