# 端行智能作图助手

这是端行科技内部使用的中文智能作图项目。员工只需要在 Codex 中拖入原图、说中文，系统会协同 Photoshop 2026、Illustrator 2026 和 AI 完成作图、复核、导出及留档。

## 第一次安装

安装前请确认：

- 已购买可正常使用的 GPT 服务。
- 已安装并登录 Codex。
- 已安装、激活 Photoshop 2026 和 Illustrator 2026。
- 现场网络和 VPN 可以正常使用。

然后：

1. 保存文件并关闭 Photoshop 和 Illustrator。
2. 双击根目录唯一的安装入口：`【客户双击这里】首次安装端行作图助手.cmd`。
3. 等待窗口显示“首次部署完成”。
4. 关闭旧的 Codex 任务，打开一个新任务。
5. 把原图拖入 Codex，直接用中文说要求。

安装文件可以重复双击；以后更新项目时，也使用同一个入口。

## 通常只记三句话

| 想做什么 | 对 Codex 说 |
|---|---|
| 开始新图 | 拖入原图后说 `做这张。` |
| 去波纹、补底纹并做矢量 | 拖入原图后说 `按端行样板做。` |
| 满意并出成品 | 看完预览和复核单后说 `通过并导出。` |

不满意时说：`退回修改：中央竖缝明显。`；第二天接着做时说：`继续上次。`

不知道下一步时，只说：`下一步做什么？`

连续处理同规格图片时，从第二张开始拖入新图后只说：`照上次规格做。`

如果经常在多种产品规格之间切换，第一张完成后说：`记住这个规格叫木纹。`。以后拖入图片只说：`按木纹做这张。`，不会误用刚才另一类产品的规格。

同规格图片较多时，可一次拖入 2～20 张并说：`这些都按木纹做。`。逐张看完预览后，只有全部满意才说：`这批都通过并导出。`

客户不需要输入文件路径、英文格式、任务编号或技术命令。重新打开 Codex 后也不用再次拖原图，直接说“继续上次”。系统默认保护原图，只有人工明确通过后才允许导出生产版。

## 安全说明

- 不覆盖客户原图。
- AI 结果必须经过指定人员人工复核。
- 复核通过后若文件再次修改，原批准自动失效。
- 正式文件统一保存到任务的“04_生产版”目录。
- 项目基于开源 PhotoshopMcpServer 扩展，采用 [MIT 许可证](LICENSE)。
